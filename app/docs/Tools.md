## 在线工具

### 房贷计算器
- 地址：`/tools/mortgage`
- 首页右上角：**房贷计算**
- 商业贷 / 公积金 / 组合贷；等额本息 / 等额本金；按月分页 / 按年汇总

### JSON 格式化
- 地址：`/tools/json`
- 首页右上角：**JSON格式化**
- 格式化 / 压缩、树形折叠展开、路径复制、双击叶子编辑（参考 JSON-handle）

### 编解码工具
- 地址：`/tools/encode`（可用 `?tab=base64|url|md5|timestamp`）
- 首页右上角：**编解码**
- 四个 Tab：
  - **Base64**：编码 / 解码（支持中文 UTF-8）
  - **URLEncode**：`encodeURIComponent` / `encodeURI`，编码 / 解码
  - **MD5**：32 位 / 16 位，大小写切换
  - **TimeStamp**：当前时间、时间戳 ↔ 日期互转（秒 / 毫秒）

纯前端，无需后台接口。刷新页面即可使用。
